# Five-user proof pilot

The first pilot is deliberately small: five people use the free seven-tool Community edition on one real, harmless task and report the product step they personally observed.

There is no purchase requirement and no reward for positive feedback. A failed install or incomplete proof loop is useful evidence.

## Run the proof

1. Install Community using the command in [README.md](README.md).
2. Confirm your host lists exactly seven Living Stack tools.
3. On a harmless task, start a scoped session, authorize one bounded action, record typed evidence, check one claim, and close the session.
4. Submit the [public feedback form](https://github.com/equinoxaifinance-rgb/living-stack-community/issues/new?template=first-proof-feedback.yml).

The form asks only for the host, the furthest product step observed, the next capability needed, and setup friction. Do not paste task content, credentials, personal data, private paths, ledger files, keys, or proprietary evidence.

## What the pilot decides

The pilot tests two separate questions:

- Does the free proof loop reach a completed session on a new user's setup?
- After that proof, is the next real need one of Complete Local's paid jobs: durable resume, recovery, signed trace export, release verification, or multi-agent coordination?

Five responses are a discovery checkpoint, not proof of broad demand. Product or landing-page changes should cite the observed responses rather than invented personas.
